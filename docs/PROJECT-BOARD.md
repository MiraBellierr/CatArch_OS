# Project Board Setup

This document defines the Day 01 task board columns and label usage for CatArch OS v1.

## Board Columns

Create a project board with these columns in order:

1. `Backlog`
2. `Ready`
3. `In Progress`
4. `In Review`
5. `Blocked`
6. `Done`

## Label Set

Create and use these labels on issues and pull requests:

- `build`
- `theme`
- `installer`
- `qa`
- `docs`
- `good-first-issue`

## Card Rules

- Every day starts with one issue titled `Day XX - <goal>`.
- Move the day issue to `In Progress` when implementation starts.
- Keep the issue in `In Review` while its PR is open.
- Move both issue and PR to `Done` only after merge checks pass.
- If work cannot continue, move to `Blocked` and add the blocker in comments.
