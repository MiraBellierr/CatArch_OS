# Package Selection Track

This checklist tracks Day 03 package review issues for the baseline in `archiso/packages.x86_64`.

## Day 03 Review Categories

Open one issue per category using title format:
`Package Review - <Category>`

Assign labels:
- `build`
- `qa`
- `docs`

## Issue Queue

- [ ] `Package Review - Boot and Base System`

- [ ] `Package Review - Fonts and Localization`
- [ ] `Package Review - Firmware and Printing`
- [ ] `Package Review - Package Management and Utilities`

## What Each Issue Must Contain

- Current package list for that category.
- Why each package is in baseline (1 sentence each).
- At least one alternative package considered (if any).
- Risk notes (size, RAM, licensing, maintenance, overlap).
- Decision: `keep`, `replace`, or `drop`.

Day 03 is complete when the baseline list is drafted and these review issues are opened.
